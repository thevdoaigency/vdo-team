Internal — Leopardo Efficiency

The Librarian. An isolated agent that turns staged assets into Monday rows.

Nothing more. It doesn't touch raw footage, doesn't touch working projects, and doesn't decide what's finished — Raj and Brando do that by staging a file in the first place.

Architecture
—

Its own agent, not a skill bolted onto VDO

The Librarian is a separate, isolated agents.list entry — its own workspace, its own memory, its own skill allowlist — sibling to VDO and Higgins, not nested inside either. Skills are cheap to add; shared memory isn't. One agent handling several jobs builds up enough accumulated context to bloat token usage and feed the same retry-loop failure mode GX10 already guards against. Isolation keeps the Librarian's context clean and its blast radius contained if something goes wrong.

SHARED: GX10 HARDWARE · OLLAMA MODEL · TELEGRAM BOT FRONT END
ISOLATED: WORKSPACE · MEMORY · SKILL VISIBILITY

What it does not do
—
  • No file watching or auto-triggering on folder changes
  • No auto-promotion from LucidLink to staging
  • No auto-upload to R2
  • No auto-wipe of anything, in this phase
  • No writing to Monday without a human confirming first
  • No scope beyond Leopardo Efficiency's board and prefix
Filename convention it reads
—

[project]_[type]_[description].[ext] — parsed straight out of the filename, no content analysis, no guessing. A file that doesn't match the convention gets flagged for a human to rename, not silently logged wrong.

E.G. CLEVELAND_DELIVERABLE_CASE-STUDY-V2.MP4 · CHICAGO_INTERVIEW_CURTIS-FULL.MP4

Definition of done — v1
—
  • Raj can stage a batch, run scan, get an accurate list back
  • Propose correctly parses well-named files and flags badly-named ones instead of guessing
  • Nothing lands in Monday without an explicit confirm
  • The agent has run against a real batch of Chicago material without a manual fix to its parsing logic
Phase 2

Once v1 is solid and lived-in for a few weeks: R2 upload folded into the confirm step, folder-watching instead of manual scan, and the same isolated-agent pattern repeated — new name, new scope, new credentials — across the other six portfolio companies.
